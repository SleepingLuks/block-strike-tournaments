# Block Strike Tournaments

Static frontend prototype for a public Block Strike tournament website.

## Files
- `index.html` — page structure and demo tournament content
- `style.css` — responsive dark/red interface
- `script.js` — RU/EN language switch and small UI interactions

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Set deployment source to **Deploy from a branch**, choose `main` and `/ (root)`.
3. Save and wait for GitHub Pages to publish.

## Current stage
This is a visual frontend prototype. Tournament cards and bracket data are demonstration content. No real admin authentication or persistent tournament database is connected yet. The next stage is to add Supabase storage and secure Telegram-based admin authentication (server-side signature validation).
